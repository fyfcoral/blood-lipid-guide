血脂管理与饮食指引

四、视频讲解（请替换以下链接为你自己的云盘地址）

血脂包括胆固醇和甘油三酯，其水平异常升高可能导致动脉粥样硬化，增加心脏病和脑卒中的风险。

理想的血脂水平：

• 总胆固醇 < 5.2 mmol/L

• 甘油三酯 < 1.7 mmol/L

• HDL-C ≥ 1 mmol/L

• LDL-C：中低风险 < 3.4，高风险 < 2.6，冠心病患者 < 1.8

血脂过高的危害

血脂持续升高会导致血管内形成斑块，造成血管狭窄，甚至引发心梗、脑梗等严重问题。

高血脂患者建议减少的食物类型

应限制摄入高油脂、高胆固醇及高糖类食物，如油炸食品、肥肉、动物内脏、含糖饮料等。

二、饮食建议与顺序：211法则

建议按“211法则”进食：

1. 先吃蔬菜 2. 再吃蛋白质 3. 最后吃主食

如果平常喝汤：1. 喝汤 → 2. 蔬菜 → 3. 蛋白质 → 4. 主食

211饮食顺序图解

先吃蔬菜和蛋白质类食物有助于平稳血糖和控制胰岛素分泌，最后摄入主食可减少脂肪积累。

三、饮食顺序的科学原理

• 蔬菜含膳食纤维，蛋白质含油脂，有助于平稳胰岛素分泌；

• 先吃主食会刺激胰岛素大量分泌，容易储存脂肪；

• 控制主食量，有助于避免肥胖；

• 吃饭速度太快可能引发胰岛素抵抗，增加肥胖风险。
